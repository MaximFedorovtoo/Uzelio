# Uzelio — концепт интерфейса 2026

Интерактивный макет нового визуального языка Uzelio. Концепция приложения сохранена: децентрализованная сеть узлов, собственная раздача, карта и трафик на главной, приложения через Uzelio, встроенные чаты со сквозным шифрованием и историей только на устройствах участников, профиль. **Рабочее приложение не изменялось.**

## Открыть

- С локального сервера: из корня проекта выполнить `python -m http.server 8787 --directory docs`, затем открыть `http://127.0.0.1:8787/designs/uzelio-2026/`.
- Либо открыть `index.html` напрямую. Шрифты Unbounded/Inter подключаются из Google Fonts; без сети используется системный fallback.
- Статичный режим для превью: `?capture=1` (останавливает анимации и раскрывает блоки).
- Фиксированные состояния: `?capture=1&screen=chats`, `&screen=profile`, `&map=1`, `&state=off`, `&chat=anna`.

## Интерактив

- Нижняя навигация «Главная / Чаты / Профиль» с переезжающей пилюлей.
- Подключение: «Отключиться» → «Не подключено» → «Найти подключение» → «Подключаемся…» → «Соединение установлено»; отмена доступна во время сопряжения.
- Раздача: остановка раздачи закрывает соединение, повторное включение возвращает возможность подключаться.
- Карта: узлы на карте и в списке, выбор узла, полноэкранная карта с маршрутами; фильтры регионов демонстрационные.
- Чаты: выбор диалога, поиск, отправка сообщения, статусы «Отправлено»/«Доставлено», ответ собеседника, вложение в макете.
- Профиль: QR-код приглашения (демонстрационный), копирование кода, устройства, лимит раздачи, режим подключения.

## Решения

- **Ocean 2.0.** Глубокий сине-чёрный фон, бирюзовый акцент только для действия и сети, мягкие слои стекла, тонкие контуры и крупные радиусы. Палитра и правила брендбука сохранены.
- **Типографика.** Unbounded для заголовков и витрины, Inter для интерфейса. Крупные заголовки, плотный трекинг, micro-подписи.
- **Композиция.** Карта и трафик интегрированы в главную; отдельные разделы «Карта» и «Трафик» не нужны. Нижняя навигация — три раздела, как зафиксировано в брендбуке.
- **Движение.** Отклик 120–180 мс, переходы 320–420 мс, появление данных до 900 мс, пружина `cubic-bezier(.22, 1, .36, 1)`. Декоративный фон и созвездие останавливаются при `prefers-reduced-motion` и в статичном режиме.
- **Честные состояния.** Поиск, отсутствие каталога, выключенная раздача и очередь сообщений объясняются текстом и действием; демонстрационные данные помечены.

## Проверено

- Chromium (headless, CDP) на 1440×900, 820×1100 и 390×844.
- Сценарии: вкладки, полный цикл подключения, отключение, раздача, карта и выбор узла, отправка сообщения и ответ, профиль, копирование токена.
- JS-ошибок в консоли нет; адаптив не даёт горизонтального переполнения.

Данные, узлы, задержки, сообщения и показатели — демонстрационные. Это концепт-макет, а не рабочая сборка.
